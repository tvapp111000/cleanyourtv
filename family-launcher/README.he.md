# Family TV Home — הלאונצ׳ר האישי

גרסה מותאמת של [CleanYourTV מאת Gathin23](https://github.com/Gathin23/cleanyourtv). קוד הלאונצ׳ר המקורי נשאר בתיקייה `launcher`; הגרסה האישית נמצאת כאן, בתיקייה `family-launcher`.

## מה כלול

- ארבעה אריחים: טלוויזיה, סרטים וסדרות, YouTube ואפליקציות.
- באנרים בעברית וברוסית בהתאם לשפת המכשיר.
- סימון בחירה לבן וכחול וניווט בשלט.
- החזקה של ארבע שניות על סרטים וסדרות או אפליקציות פותחת הגדרות תצוגה: בחירת אפליקציות לכל קטגוריה, שמירה, ביטול ואיפוס.
- שינוי סדר נפרד לכל קטגוריה: בחרו ״שינוי סדר״, אישור להרמה, חצים למעלה ולמטה, אישור להנחה, ״החל סדר״ ואז ״שמור שינויים״.
- החזקה של ארבע שניות על טלוויזיה פותחת בחירת אפליקציית ברירת מחדל לטלוויזיה ולסרטים וסדרות מתוך האפליקציות שבקטגוריה.
- לחיצה קצרה פותחת את ברירת המחדל שנבחרה; ניתן לבחור גם פתיחת רשימת הקטגוריה.
- רשימות האפליקציות מציגות את באנרי האפליקציות. כשאין באנר, משתמשים בסמל.
- באנרים בגודל בסיס 160×90dp, המתאים לצפיפות התצוגה של Android TV.

## בנייה

נדרשים Android SDK 34, Build Tools 34.0.0 ו־JDK 17 ומעלה. הגדירו `ANDROID_HOME` ו־`JAVA_HOME` במחשב שלכם.

```powershell
cd family-launcher
.\gradlew.bat --no-daemon assembleRelease
```

ב־Linux/macOS:

```sh
cd family-launcher
chmod +x gradlew
./gradlew --no-daemon assembleRelease
```

הקובץ נוצר ב־`app/build/outputs/apk/release/app-release.apk`. הגרסה משתמשת במזהה `com.gathin.tvhome`, כמו המקור. שדרוג דורש חתימה זהה להתקנה הקיימת; המאגר אינו כולל את מפתח החתימה מהמכשיר האישי.

## התקנה בשיאומי או Android TV

הפעילו אפשרויות מפתח וניפוי במכשיר שלכם ואשרו את המחשב. התקינו את דרישות כלי החיבור לפי התיעוד המקורי בתיקיית `tools`.

```powershell
.\family-launcher\build-and-install.ps1 -TvHost <TV_IP> -StockLauncher none
```

האפשרות `none` מתאימה לעדכון כאשר הלאונצ׳ר כבר מוגדר כמסך הבית. בהתקנה חדשה קראו תחילה את [הנוהל המקורי](../PROMPT.md), גבו את המכשיר ואמתו שמסך הבית החדש עובד לפני השבתת מסך הבית המקורי. אין צורך לבצע ניקוי אפליקציות כדי להשתמש בלאונצ׳ר. בסיום העבודה כבו ניפוי ובטלו הרשאות חיבור מהמחשב.

## קבצים ופרטיות

המאגר כולל קוד ונכסי תצוגה בלבד. הוא אינו כולל גיבויי מכשיר, בחירות האפליקציות האישיות, כתובת החיבור של המכשיר, מפתחות ADB, מפתחות חתימה או APK שנבנה מקומית.
